## Project Description
This project demonstrates Model Binding in ASP.NET Core MVC by creating a simple login page. It uses a LoginViewModel with Data Annotations for server-side validation. The application validates hard-coded credentials (Username: admin and Password: 123456). If the credentials are correct, the user is redirected to the Welcome page. Otherwise, an error message is displayed.
